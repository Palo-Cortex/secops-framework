
#### Correlation Rules

##### SOC CrowdStrike Falcon - Endpoint All Alerts

- The rule no longer writes the host's operating system into the built-in `hostos` issue field. Writing an event value into a built-in issue field can leave the issue's playbook pending: the playbook cannot update the issue, or the run completes while its status stays pending. The OS is still in the event and the data model.
- The SOC Framework no longer reads an Endpoint OS value from CrowdStrike endpoint issues. Other sources are unchanged.
- Tenants that run their own copy of this rule must remove the `hostos` mapping from the copy; a pack upgrade does not change a copied rule.
