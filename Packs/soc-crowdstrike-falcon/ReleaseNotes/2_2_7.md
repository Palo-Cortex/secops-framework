
#### Correlation Rules

##### SOC CrowdStrike Falcon - Endpoint All Alerts

- The alert description now ends with the detection's file activity — the files the process accessed and wrote, as `folder|file` paths — so the issue assessment sees what the process touched. Ransomware detections (T1486) previously reached the assessment with only the process, hash and path, which held the verdict at medium confidence and kept emergency response from containing on them.
- Detections with no file activity keep their description unchanged.
- The new stages use only functions already proven in this real-time rule; the post-configuration guide lists the functions that silently stop a real-time rule, and how to run the rule on a schedule instead.
