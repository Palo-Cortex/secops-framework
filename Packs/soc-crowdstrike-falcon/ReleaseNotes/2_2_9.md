
#### Correlation Rules

##### SOC CrowdStrike Falcon - Endpoint All Alerts

- The pack now installs on tenants whose CrowdStrike data has never carried some detection fields (`user_principal`, `template_instance_id`, `dns_requests`, `network_accesses`, `files_written`, `files_accessed` and others). The rule read these as dataset columns, and the install was rejected (101704) when a column did not exist yet. It now reads every detection field from `rawJSON`, except `name`, `composite_id`, `aggregate_id`, `user_name`, `cmdline` and `pattern_disposition_details`, which every detection carries and the integration rewrites.
- Issue fields and the alert description are unchanged.
