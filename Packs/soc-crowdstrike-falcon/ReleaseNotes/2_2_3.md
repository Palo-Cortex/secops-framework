## [2.2.3] - October 2026

### Fixed

#### SOC CrowdStrike Falcon - Endpoint All Alerts — array-of-object fields excised, `hostos` restored

`dns_queries` and `remote_ips` were assigned directly from `dns_requests` and
`network_accesses`. Both are arrays of objects, so the alert fields fed by them
carried a raw JSON blob rather than a value — confirmed on tenant alerts, for
example `dns_query_name` holding
`[{"domain_name":"anto-int.com","request_type":"AAAA",...}]`.

Both alters are dropped in this version, along with the seven alert fields that
depended on them (`dns_query_name`, `dnsqueryname`, `dns_requests`,
`network_accesses`, `remoteip`, `postnatdestinationip`, `action_remote_ip`) and
the two columns in the `fields` clause.

> Superseded by 2.2.4, which restores these fields with proper JSON extraction.
> Removing them also removed artifacts XSIAM groups on, which fragmented case
> volume. The excise was the wrong remedy for a parsing problem.

#### `hostos` restored

The removal of `hostos` in commit `c7f9a69` is reverted. The premise was wrong:
`device_platform_name` is derived from `device->platform_name`, passes through
the trailing wildcard in the `fields` clause, and the raw field is populated.
A known-good tenant rule keeps `hostos` as well. It was never broken, and the
playbook queue hang it was meant to address has no identified cause.

### Changed

#### Contract is now the source of truth

Hand edits that existed only on the emitted rule are back-ported into
`schemas/vendors/crowdstrike-falcon/`, so `emit` is no longer destructive:
seven alert fields (`agentossubtype`, `hostfqdn`, `hostip`, `initiatormd5`,
`osparentid`, `endpointisolationstatus`, `categoryname`) and four `device_*`
derivations (`os_version`, `platform_name`, `status`, `fqdn`). The working
modeling rule is also back-ported so a regeneration reproduces it rather than
replacing it. Roundtrip is clean on all four generated files.

`system: false` is dropped — no other correlation rule in the repository
carries it, and it came from a tenant download.
