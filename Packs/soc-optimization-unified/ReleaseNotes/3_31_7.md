##### SOCCommandWrapper

- A read-only action (enrichment or investigation phase) whose vendor command fails, for example
  with an HTTP 429 rate limit, no longer stops the playbook. The failure is still written to the
  War Room, the execution context and `xsiam_socfw_ir_execution_raw` (`action_status` = `failed`),
  the action's `UC.*` output keys are cleared, and the playbook continues without that result.
- Actions that change something (isolate, block, revoke, close) still stop the playbook when their
  command fails, so a failed containment is never read as one that ran.
