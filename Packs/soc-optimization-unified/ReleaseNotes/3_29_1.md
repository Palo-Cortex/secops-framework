#### Scripts

##### SOCFWConfig

- New `command=triage`. With no arguments it shows Auto Triage's score threshold and age
  window: the value `SOCOptimizationConfig_V3` ships, this tenant's value, and the one Auto
  Triage uses.
- `score_threshold=<n>` sets the highest case score that may close; `off` ignores the
  score, so every unstarred New case older than the window closes. `window_hours=<n>` sets
  the age below which a case is never closed. `default` on either returns it to the shipped
  value.
- The values are kept in `SOCFWTenantConfig`, so a pack upgrade that rewrites
  `SOCOptimizationConfig_V3` no longer resets them. Dry run unless `apply=yes`; every change
  is recorded as a `config_change` row.

##### SOCAutoTriageScoreFilter

- A threshold or window set with `!SOCFWConfig command=triage` wins over the value the
  Auto Triage JOB passes from `SOCOptimizationConfig_V3`. The run's summary and outputs say
  which value it used and where it came from (`AutoTriage.score_threshold`,
  `.window_hours`, `.settings_from`).
- With the score `off`, the score checks are skipped; the starred, status, domain, manual
  score and age guards still apply.
- An unusable tenant value stops the run before anything closes.
- `score_threshold` and `window_hours` are no longer required arguments, so
  `!SOCAutoTriageScoreFilter dry_run=true` runs from the War Room with the tenant's or the
  default values (40, 6 hours).
