#### Lists

##### SOCFrameworkPhasePolicy_V3

- The star rule (`phases.triage.elevate`, `malicious_high_confidence`) now also requires the
  assessment to say an analyst is needed (`escalate_recommended`). A case stars when the issue is
  malicious, at high confidence, and needs an analyst.
- Malicious work the assessment says needs no analyst - a phishing email delivered and never
  clicked, a threat a control already stopped - is still assessed and stays visible, unstarred.
  If a later issue in the same case needs an analyst (a click, an execution), the case stars then.
- The condition is AND'd, so it can only narrow what stars: nothing that did not star before stars
  now. It accepts `true` and `"true"`; a missing value never matches.
- A tenant that detached and edited this list keeps its copy; apply the same change there or
  reattach.
