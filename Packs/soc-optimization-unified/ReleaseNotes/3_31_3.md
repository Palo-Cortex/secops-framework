##### SOCCommandWrapper

- A shadow row now records `action_status: no_instance` with `action_time_minutes: 0` when no
  enabled instance on the tenant serves the vendor command. The row is kept so the tenant can see
  which integration the action needs; a simulated row no longer credits time saved to a product
  that is not installed. Commands an enabled instance does serve are simulated as before, and the
  live path is unchanged.
