#### Scripts

##### SOCFWConfig

- New `command=mode`. With no arguments it lists the modes in `SOCFWConfigModes` next to this
  tenant's current settings and says which mode the tenant matches (or `custom`).
- `mode=<name>` applies one: it sets every shadow switch the mode names, for the automated actors
  only, and turns the Auto Triage JOB on. `owner=<email>` sets the JOB's owner; without it, a JOB
  that has no owner stays off and the rest is applied.
- `mode=default` removes the mode settings and turns Auto Triage off, back to what the pack
  installs.
- A mode never changes the Auto Triage threshold or window, analyst actions, or the emergency
  protect and role settings. Dry run unless `apply=yes`. Every change is recorded as a
  `config_change` row.
- `status` now shows the Auto Triage score threshold and age window (`SOCFWConfig.Status.triage`)
  and which mode the tenant matches (`SOCFWConfig.Status.mode`).

##### SOCCommandWrapper

- Takes each action's minutes and category from `SOCFWTenantConfig` → `value` first, field by field,
  then `SOCActionTimeMap_V3`. An unusable tenant value falls back to the shipped one.

##### SOCFWHealthCheck

- Same command, now read-only, with a new Configuration section graded from
  `!SOCFWConfig command=status`: the tenant config list, the mode the tenant matches and what
  runs for real, required customer values, each framework JOB (a JOB that is on with an owner
  who is not a user is a FAIL), Auto Triage settings and emergency response.
- No longer checks or creates the retired `SOCFW_UniversalCommand` list.
- Arguments and outputs (`SOCFWHealthCheck.*`) now match what the script reads and writes.

##### setValueTags

- Replaces `setValueTags_V3`. Views and sets each action's value (the analyst minutes it saves and its
  category). Values set on a tenant go in `SOCFWTenantConfig` under `value` and win over the shipped
  `SOCActionTimeMap_V3`, which the platform does not let a script change; they survive upgrades.
  `action=list_all` shows where each value comes from and names the framework actions with no value
  (they record 0 minutes). `delete` goes back to the shipped value.
- Same action names (`list_all`, `list_by_type`, `list_by_tag_or_name`, `add`, `update`,
  `delete`); `tag` is now the action name, `time` is minutes, `category` is the action's category.

#### Lookups

- `value_tags` is retired and no longer installed. Nothing reads it; value comes from
  `SOCActionTimeMap_V3`.

#### Lists

##### SOCFWConfigModes

- New. Four modes, each setting the same switches so changing modes leaves nothing behind:
  - `pov`: starring and benign AI close run for real, Auto Triage on, all containment recorded in
    shadow.
  - `star_and_triage`: starring runs for real, Auto Triage on; the AI closes nothing and nothing is
    contained.
  - `contain_identity_and_hosts`: `pov` plus severity raise, closing contained issues, and
    emergency revoke of sessions and tokens and isolation of workstations.
  - `contain_all`: every automated action in the list runs for real, including emergency email
    retract and domain or address blocks.
