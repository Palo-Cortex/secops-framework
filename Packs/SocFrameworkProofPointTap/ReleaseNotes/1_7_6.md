
#### Correlation Rules

##### SOC Proofpoint TAP - Threat Detected All Alerts

- The rule now ships **REAL_TIME** from the contract, with `crontab`, `search_window`, `simple_schedule` and `timezone` emitted as explicit nulls. It previously shipped SCHEDULED, so every real-time deployment required cloning the rule and changing the execution mode by hand on the tenant.
- Cloud Identity Engine enrichment is unchanged and remains **off by default** — the `socfw_identity_map` join stays wrapped in its `/* */` block. This is required for real-time operation, because a join cannot run in a REAL_TIME rule.
- Switching CIE on is still contract-driven: set `cie_enabled: true` and re-emit, which also applies the `cie_schedule` the contract declares (`*/10 * * * *`, 25 hour search window) and moves the rule to SCHEDULED.
