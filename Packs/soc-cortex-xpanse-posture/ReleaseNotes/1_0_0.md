# soc-cortex-xpanse-posture v1.0.0

Initial release. First Posture-lifecycle vendor pack for a unified-platform-native data source.

## Framework contract extension

Added two new categories to `SOCFrameworkNormalizeMap_POSTURE`:

**`posture_attack_surface`** - Cortex Xpanse exposed-service findings normalized into `SOCFramework.CloudPosture.*` contract. Mappings cover target IP/hostname/port, application protocol, certificate issuer/expiry, and geographic exposure. Dedup on target IP + port.

**`posture_vulnerability`** - Cortex Xpanse CVE-bearing findings normalized into the same contract. Mappings cover CVE ID, CVSS score/vector, affected package, and fixed version. Dedup on CVE ID + target IP.

## Vendor pack

- Routing entry `ds_panw_asm: Posture` added to `SOCProductCategoryMap_V3` — Foundation Product Classification routes on the DS:PANW/ASM tag
- Six-panel operational metrics dashboard (severity, status, trend, top types, geographic exposure, top assets)
- No correlation rule or modeling rule required — Xpanse-XSIAM native integration produces XDM-normalized records at platform ingestion

## Architecture pattern

This release establishes the first Posture-lifecycle vendor pack precedent for unified-platform-native data sources. The same shape applies to AI-SPM, CIEM, and future Cortex Cloud sources that write directly to the unified `issues` dataset.
