# Release notes — hand-deployed AI content

The playbooks and prompts in `ai/nist-ir/` live outside the packs and carry no
pack version, so their changes are recorded here instead: one dated file per
change set, newest name sorts last.

Every entry uses three parts and stays terse:

- **What you get** — one line on why a DC should care.
- **Changed** — component names only (pack · playbook · prompt).
- **Update** — numbered operator steps, one line each. Only hand-steps are
  spelled out; a change that rides a pack update or a playbook upload is never
  written as a hand-edit.
