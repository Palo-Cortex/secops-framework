# 3 Nov 2026 — Time saved counts only what ran, and only what the tenant has

**What you get:** the Value Metrics dashboards stop crediting time saved to commands that
failed, and the Shadow dashboard stops crediting shadowed actions to integrations the tenant
does not have. On a PoV tenant the time-saved tiles now reflect what the customer's own tools
would actually do.

**Changed:** `soc-framework-nist-ir-ai` pack (`NIST IR - Value Metrics (AI)`,
`NIST IR - Value Metrics Shadow Mode (AI)`: five time-saved widgets each, the Shadow
"SOC Minutes Returned by Product" pie) · `soc-optimization-unified` pack (`SOCCommandWrapper`:
shadow rows record `no_instance` at 0 minutes for commands no enabled instance serves).

**Update:**
1. Pack → `soc-optimization-unified` 3.31.3 or later
2. Pack → `soc-framework-nist-ir-ai` 1.6.1 or later
3. Hard-refresh the dashboards after the install
